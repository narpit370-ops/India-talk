# Recommended launch order

1. Create Firebase project and Android app.
2. Create SMS/OTP provider.
3. Create production PostgreSQL.
4. Deploy backend behind HTTPS.
5. Connect FCM, OTP, storage and TURN.
6. Add real Android UI/network modules.
7. Run internal/closed testing.
8. Complete privacy policy + Play Console Data Safety.
9. Generate signed AAB.
10. Submit to Play Console.
11. Start with a staged rollout and monitor crashes, latency and abuse reports.
