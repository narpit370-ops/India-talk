# INDIA TALK — Production-ready structure v2.0
Founder: Arpit Nayak 🇮🇳

This package upgrades the MVP into a production architecture covering:
1. OTP authentication
2. Real-time messaging
3. Media upload/storage
4. Push notification integration points
5. Group chat
6. Voice/video calling architecture with WebRTC + TURN
7. PostgreSQL data model
8. Security/rate-limit scaffolding
9. Reporting/blocking safety module contracts
10. Android production module map
11. Play Store launch checklist

This is a production-ready STRUCTURE and implementation scaffold, not a claim that
third-party services (SMS, cloud storage, FCM, TURN) are already connected. Those require
your accounts, credentials, domains, and deployment environment.

See docs/PRODUCTION_CHECKLIST.md before launch.
