# India Talk — Mobile APK Build

1. Install AndroidIDE on your Android phone.
2. Extract this ZIP.
3. Open the folder containing settings.gradle/settings.gradle.kts.
4. Let Gradle sync and install required SDK/build tools.
5. Use Quick Run / Assemble Debug to create the APK.
6. Install the generated APK on the phone.

Important: This package is Android source code, not an APK. Firebase, OTP, realtime messaging, storage and calls require production credentials/backend configuration.
